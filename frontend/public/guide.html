Goreach 使用手册

注册订阅 · 密钥配置 · 接入 AI 平台

适用对象 Goreach 订阅用户
官方网址 https://www.goreach.es/home
本手册包含 账号注册与订阅支付、控制台 API 密钥创建、CC Switch（Claude Code / Claude 桌面端）与 WorkBuddy 的接入配置
Goreach 团队 提示：点击任意截图可放大查看高清原图
一

注册和支付

首先访问 Goreach 官网完成账号注册，并按需选择订阅方案完成支付。

登录域名 https://www.goreach.es/home

（一）注册账号

打开登录域名，按页面提示填写信息完成账号注册。（联系工作人员开通）

（二）支付订阅

注册完成后，选择所需的订阅方案并完成支付。

二

控制台配置

订阅生效后，进入控制台查看订阅信息，并创建用于接入 AI 平台的 API 密钥。

（一）查看订阅信息

（二）创建 API 密钥

第一步选择订阅所示的分组。

第二步创建密钥。

第三步创建成功，在红框处复制密钥信息。

!
重要：API 密钥是您账号的访问凭证，请妥善保管，切勿泄露给他人。
三

接入 AI 平台

获取 API 密钥后，即可在常用 AI 工具中接入 Goreach。各平台通用的配置参数如下：

通用配置参数速查

参数项 填写内容
名称 / 供应商 自定义
API KEY / API 密钥 复制 Goreach 控制台中创建的 API 密钥
请求地址 / 接口地址 https://www.goreach.es/

（一）CC Switch 配置 Claude Code

下载地址 https://ccswitch.io/zh/docs?section=getting-started

步骤 1左侧选择 Claude Code（Windows PowerShell 命令符界面）。

步骤 2右侧添加供应商。

步骤 3选择自定义配置。

  • 名称：自定义
  • API KEY：复制 Goreach API 密钥里面的信息
  • 请求地址： https://www.goreach.es/

步骤 4点击刚刚创建完成的供应商，在右侧红框处选择使用的目录，然后打开终端。

步骤 5成功打开 Claude Code 控制界面。

（二）配置 Claude 桌面端

如果已经安装 Claude Code 桌面端，配置步骤如下：

步骤 1左侧选择 Claude Desktop，右侧添加供应商。

步骤 2选择自定义配置。

  • 名称：自定义
  • API KEY：复制 Goreach API 密钥里面的信息
  • 请求地址： https://www.goreach.es/

步骤 3配置完成后，打开电脑上安装的 Claude Code 应用，重新登录连接即可使用。

（三）配置 WorkBuddy

步骤 1选择配置自定义模型。

步骤 2按下表填写配置信息。

配置项 填写内容
供应商 自定义
接口地址 https://www.goreach.es/
API 密钥 复制 Goreach 里面配置的 API 密钥
模型名称 claude-opus-5-5
i
提示：WorkBuddy 每次只能添加一个模型。如需使用其他模型，可重复以上自定义步骤多次添加。
